深鲸守护 · Agent 权限边界 —— 4 条规则
 
[high] SCOPE-WILDCARD-TOOLS
Agent 工具权限使用通配符
依据：MCP 官方文档 · 工具与权限模型；最小权限原则（NIST SP 800-53 AC-6）—— 只授予完成任务所必需的权限
 
[high] SCOPE-FS-ROOT
Agent 文件访问范围是根目录或整个用户目录
依据：MCP 官方文档 · Server 部署建议（限制可访问目录）；最小权限原则 —— 文件系统访问应限定在必要目录
 
[medium] SCOPE-NET-ANY
Agent 网络访问无限制
依据：OWASP Top 10 for LLM Applications — LLM06 Excessive Agency：应限制智能体可访问的资源与网络范围；MCP 官方文档
 
[medium] SCOPE-NO-DECLARATION
Agent 配置里找不到权限声明
依据：MCP 官方文档 · Server 能力声明；最小权限原则 —— 权限应显式声明而非默认全开
