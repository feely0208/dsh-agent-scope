· Agent 工具权限使用通配符
位置 mcp.json:4
证据 allowedTools": ["*"
依据 MCP 官方文档 · 工具与权限模型；最小权限原则（NIST SP 800-53 AC-6）—— 只授予完成任务所必需的权限
建议 Agent 的工具权限写成 `*` / `all` / `any` —— 意味着它能调用**所有**工具（读文件、执行命令、发网络请求）。Agent 的权限就是它的**爆炸半径**：一旦被提示注入控制，能做的事等于你给它的全部权限。改成白名单，只列真正需要的工具。
· Agent 文件访问范围是根目录或整个用户目录
位置 mcp.json:3
证据 args": ["-y", "@modelcontextprotocol/server-filesystem", "/"
依据 MCP 官方文档 · Server 部署建议（限制可访问目录）；最小权限原则 —— 文件系统访问应限定在必要目录
建议 Agent 的文件访问路径指向 `/`、`~`、`C:\\` 或整个用户目录 —— 意味着它能读写**你所有的文件**（包括 ~/.ssh、~/.aws、浏览器数据）。这些正是凭据最集中的地方。改为只开放项目目录，并且是只读优先。

· Agent 网络访问无限制
位置 mcp.json:5
证据 allowedDomains": "*
依据 OWASP Top 10 for LLM Applications — LLM06 Excessive Agency：应限制智能体可访问的资源与网络范围；MCP 官方文档
建议 Agent 的网络访问没有限制（无白名单、允许任意出站）—— 意味着被注入后可以把你的数据发到任意外部地址，或读取内网服务。OWASP 把这归为 **LLM06 Excessive Agency**。建议：出站域名白名单 + 禁止访问内网网段。
